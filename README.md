# PR. Desenvolupem el nostre projecte. Implementació
Autor: **Paula Margarit Corominas**
## Descripció
Aquest projecte proposa el desenvolupament d’una aplicació web d’organització de plans en grup. Aquesta podria resoldre els problemes que moltes persones i grups tenen i que genera desorganització, malentesos i desmotivació. 

És una extensió web basada en Manifest V3 que funciona amb una acció de popup page, i és compatible amb Firefox i Chrome.
## Funcionament
La proposta busca abordar aquesta problemàtica mitjançant una solució que centralitzi totes les funcionalitats necessàries: calendari compartit, assignació de tasques, votacions per a la presa de decisions i control de despeses. L’objectiu és millorar la comunicació entre els participants del grup, facilitar la col·laboració i reduir l’esforç i el temps dedicat a l’organització de plans. 

L’aplicació aporta diversos avantatges: centralitzar la informació en un únic espai, reduir conflictes gràcies a una comunicació més clara i estructurada, estalviar temps en la presa de decisions, i facilitar el control de pagaments i la gestió d’assistència.

## Instal·lació
1. Descarrega el repositori.  
2. Obre el navegador (per exemple Chrome) i ves a extensions.  
3. Activa **Mode desenvolupador**.  
4. Clica **Carregar des d’una carpeta**.  
5. Selecciona la carpeta del projecte.
